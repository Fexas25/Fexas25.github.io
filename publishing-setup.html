写作与发布

打开管理中心，使用管理员邮箱验证码登录。

  • 写新文章：填写栏目、标题和正文，输入时自动保存在本机，也可导入 Markdown、插入图片并发布。
  • 发布新项目：上传 HTML 或构建好的静态网站 ZIP，也可填写外部链接。上传后保存草稿、预览，再发布。
  • 草稿管理：继续编辑未发布内容。文章草稿保存在当前浏览器，可打包备份和恢复；项目草稿保存在后台。旧写作页草稿可在这里备份。
  • 已发布文章 / 已发布项目：各自查找和修改，调整公开或密钥访问，删除后可从对应回收站恢复。
  • 项目文件：使用相对路径；最多 100 个文件、合计 20 MB，单文件最多 5 MB。更新时上传完整项目包，原网址不变。需要服务器运行的程序需单独部署。
  • 密钥访问：标题可被搜索，正文及托管项目文件需要解锁。外部网站自行控制权限；曾经公开的 Git 历史和下载副本无法收回。
  • 留言管理：审核和回复留言。

遇到版本冲突时，先备份当前草稿，再重新打开最新内容。曾经公开的内容可能仍存在于历史记录或外部缓存中。

网站代码更新仍由 GitHub 自动检查和部署。日常文档更新无需等待网站重新构建。
