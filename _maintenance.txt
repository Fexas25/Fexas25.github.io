检查与部署
- npm ci --prefix _community（后端 Markdown 渲染依赖，检查前安装）
- npm test --prefix _community；npm run build --prefix _community
- npm ci --prefix _checks
- npm test --prefix _checks
- 正式 Jekyll 构建到 _site 后运行：
  python _checks/links.py _site
  python _checks/seo.py _site
  python _checks/search-index.py _site
  npm run test:browser --prefix _checks
- 自动部署以 .github/workflows/pages.yml 为准；浏览器测试模拟后端，不提交真实留言或占用翻译额度。
- 网站检查不自动部署 Cloudflare Worker；后端改动需要单独验证和部署，保留原绑定、Secret 与数据库记录。

备份与恢复（2026-10-13 核验）
- D1 Time Travel 自动保留免费方案最近 7 天的恢复历史，无需新增服务。已确认当前及一小时前的恢复点，并把真实 SQL 导出在内存数据库中恢复：10 篇文档、2 条留言、1 条回复，完整性及外键检查通过；未回滚线上数据。
- 单篇误删优先在管理中心回收站恢复。全库误改才考虑 Cloudflare 控制台 D1 → mx-community → Time Travel；先导出当前数据库，确认目标时间。全库回滚会同时影响文章、留言、回复和翻译缓存，不能只恢复某一篇。
- documents 保存正文、公开/私密状态、密钥哈希、修订号及回收站状态；messages 和 message_replies 保存留言与回复。写作页上传后内嵌正文的图片随数据库保存；原站图片仍需保留 Git 仓库，外部图片链接不包含图片文件。

- 长期留档可在 D1 控制台导出 SQL，保存到个人加密存储；私密正文包含在导出中，切勿上传公开仓库或 CI 附件。当前未新增长期备份任务，7 天历史不能替代长期留档。
