留言与翻译配置

当前已配置：留言与翻译使用 mx-community Worker，数据库为 mx-community。日常更新文章无需重复配置，下方步骤用于以后维护或迁移。

这两个功能共用独立的 Cloudflare Worker，不涉及 GitHub 登录发布。只需维护中文文章；English 按钮自动翻译网页文字并缓存。未配置时保留原文，留言不可提交。

1. 注册与免费计划

在 Cloudflare 注册账号，保持 Workers Free。不要开通付费订阅。Workers AI 有每日免费额度；免费额度耗尽后翻译会暂时不可用，页面保留原文。程序还设置了每天最多 200 个未缓存翻译请求，缓存命中不调用模型；这个应用限制不等同于 Cloudflare 的计费单位。

2. 创建数据库

在仓库的 _community 文件夹执行：

npx wrangler login
npx wrangler d1 create mx-community

浏览器登录由你本人完成。将返回的 database_id 填入 _community/wrangler.jsonc，替换 REPLACE_AFTER_CREATION，再执行：

npx wrangler d1 execute mx-community --remote --file=schema.sql

3. 添加防刷验证

在 Cloudflare 控制台打开 Turnstile，创建 Managed 类型组件，允许域名 fexas25.github.io。记下公开的 Site key，Secret key 只存到 Worker：

npx wrangler secret put TURNSTILE_SECRET
npx wrangler secret put RATE_SECRET

第二个密钥使用随机长字符串，用于限流标识；不要提交到 GitHub。若 Cloudflare 提示接受协议，由你本人确认。

4. 发布并连接

npx wrangler deploy

把生成的 HTTPS Worker 地址和公开 Site key 填入根目录 community-config.js 的 origin 与 siteKey。提交到 GitHub，等待自动部署完成。无需写入 API Token 或任何密钥。

5. 审核留言

打开留言管理页 ↗，输入管理员邮箱，使用邮件验证码登录。写作页也有“管理留言”入口。

  • 待审核：点击“通过”后公开；可以勾选多条后批量通过。
  • 已公开：点击“隐藏”，留言会回到待审核区。
  • 回收站：移入后不再公开，随时可以恢复到待审核区。

管理页仅允许已配置的管理员邮箱进入。关闭页面不等于退出登录，使用公共设备时请点击“退出登录”。登录过期后重新获取验证码即可。

维护与备用审核方式

管理服务为 mx-guestbook-admin，与访客留言和翻译的 mx-community 分开部署，共用现有数据库。管理员邮箱只保存在管理 Worker 的 ADMIN_EMAIL 密钥和 Access 允许规则中。更换邮箱时需要同时修改两处。

维护代码在 _community/admin。执行 npm ci、npm test 和 npm run build 完成检查；部署使用 npx wrangler deploy，首次部署需设置 ADMIN_EMAIL 密钥并创建对应 Access 应用。

如管理页暂时不可用，可在 Cloudflare D1 Console 查看并审核：

SELECT id,name,message,created FROM messages WHERE approved=0 ORDER BY id DESC;
-- 将 123 替换为要公开的留言 ID：
UPDATE messages SET approved=1 WHERE id=123;
-- 隐藏该留言：
UPDATE messages SET approved=0 WHERE id=123;
-- 移入回收站（保留记录）：
UPDATE messages SET approved=-1 WHERE id=123;

6. 验证

提交一条测试留言，在控制台审核后确认手机与另一台设备都能看到。打开一篇文章点击 English，确认正文翻译和切回中文正常；新增文章也走相同流程。翻译属于机器翻译，原文始终可查看，代码、输入内容和私人草稿不会发送到翻译服务。
