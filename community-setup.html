留言与服务

打开留言审核 → · 打开写作页 →

使用管理员邮箱和邮件验证码登录。待审核留言点击“通过”后公开；“隐藏”可撤回公开状态；回收站中的留言可以恢复。支持勾选后批量处理。

翻译与密钥访问

只需维护原文，右上角 English 会自动翻译并缓存公开内容。代码、输入内容、草稿和私密正文不参与自动翻译。暂时无法翻译时会保留原文，可使用 Retry 重试。

私密内容保存在独立后端，需同时持有链接和密钥才能打开，正文不进入公开仓库；标题和标签仍可在列表和搜索中找到。密钥不存入草稿备份；遗失后登录写作页更换。

现有配置保留每日新翻译请求上限，额度不足时保留原文，无需为日常使用开通付费订阅。

服务与配置位置
  • _community/：留言、翻译和私密访问 Worker；schema.sql 定义 D1 表，wrangler.jsonc 记录现有数据库绑定。
  • community-config.js：公开 Worker 地址和 Turnstile Site key。
  • _community/admin/：统一文档与留言管理页，共用现有 D1 数据库，受 Cloudflare Access 保护。
  • _publishing/：旧 GitHub 登录服务，当前管理中心已改用邮箱验证。

现有 Worker 和数据库均名为 mx-community，管理服务为 mx-guestbook-admin。日常发布文章不用重新建库或配置账号。

发布社区服务时需同时包含 worker.mjs 、documents.mjs 与 private.mjs。保留现有 D1、AI 绑定及 TURNSTILE_SECRET、RATE_SECRET；新数据库使用 schema.sql；已有数据库使用 migrations/ 中尚未执行的增量迁移，不要重建或清空已有数据库。

更换管理员邮箱时，同时更新管理 Worker 的 ADMIN_EMAIL Secret 和 Access 允许规则。关闭页面不等于退出登录，公共设备使用完请点“退出登录”。

维护检查

网站每次推送都会先检查构建、链接、搜索信息、关键功能与手机浏览器，全部通过才部署。管理服务还有独立的登录与权限检查。

维护服务后，核对留言可进入待审核区、通过后可见，翻译可恢复原文，错误密钥无法打开私密内容。测试只用无个人信息的内容，完成后清理测试记录。
